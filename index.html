voice-alerts

Spoken notifications for coding agents. When an agent needs permission, asks a question, has a plan ready or finishes a long job, voice-alerts says which session it is and what it needs, then stays quiet.

  • Holds back during calls on Windows, then nudges you afterwards.
  • Sessions take turns, so voices never talk over each other.
  • Speaks once per event, even when several hooks fire.

Works with Claude Code, Codex CLI, Gemini CLI, GitHub Copilot CLI, Cursor, OpenCode and Aider.

CU Boulder DaSSA Hackathon, top-5 finish, 2023

Predictive maintenance for aluminum recycling

A Random Forest flags bad decoating cycles in aluminum scrap recycling from furnace sensor readings, so maintenance can step in before costly dross builds up. Tuned for recall, because a missed bad cycle costs far more than a false alarm.

Caught 469 of 498 bad cycles on held-out data (94% recall) at 75% precision, with 0.988 AUC.

Python, scikit-learn, XGBoost, SMOTE, GridSearchCV

Text-mining project, 2025

Social media misinformation, an NLP study

1,054 news articles on whether platforms should be held responsible for misinformation, with stance labels from a BERT model, LDA topics, clustering and classifiers that predict an article's stance.

SVM reached 68.7% on three-way sentiment and 62.6% on four stances, against a 50% majority-class baseline.

The labels come from a model, not human annotators, so accuracy measures agreement with those labels.

Python, scikit-learn, NLTK, Hugging Face Transformers, R
